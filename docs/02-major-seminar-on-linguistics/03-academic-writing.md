# アカデミック・ライティング
## スクラップしないで
新聞とか雑誌のスクラップ、したことありますか。お気に入りの記事を紙面から切り取って、ノートに貼り付ける。それを繰り返すと、立派なスクラップブックになりますね。

ひょっとして、卒業論文に書く「先行研究」も、これと同じだと思っていませんか。つまり、色々な論文から、必要なところを切り取って自分の論文にコピペする。あるいは、まったく同じ文章をコピペすることはよくないと思い、一部の単語だけを別の単語に言い換える。先行研究は、このような作業をするところではありません。過去に行われた研究を並べるだけではないということです。みなさんは山ほどある先行研究の中に、自分の卒論の「居場所」を見つける必要があります。

- この分野では、これまで何がわかっていて、何がわかっていないのか。
- 自分の問いは、どの先行研究の延長線上にあるのか。
- 自分の研究は、既存の研究とどこが違うのか。

このようなことを考えながら先行研究をまとめ、自分の研究がこの研究史の中に、どのように位置づけられるのかを示さなければならない。先行研究は単なる「まとめ」ではなく、どちらかというと「対話」に近いものです。先行研究は、過去の研究者たちと対話をしながら、自分の問いを研ぎ澄ましていく作業と言えるでしょう。

## 引用と要約
論文では、先行研究を**引用**する必要があります。

ここで示す一部の例は、以下の本を参考にしています。

### 直接引用（quoting）
次のような場合は、原文の一字一句をそのまま、つまり、**直接引用**の方がいいでしょう。

- 原文の表現が強烈、あるいは、独特な表現で、目立つような場合
- 原文の具体的な表現が、論証をするうえで重要な役割を果たす場合
- 特定の物事や概念に対して、原文ではどのような言い方をしているのかを示したい場合
- 間接引用や要約をするより、直接引用の方がより明確に書き手の意図や意味が伝わる場合

「間接引用や要約に比べて直接引用の方が楽」、あるいは、「原文を言い換える自信がない」といった理由で直接引用を選んではいけません。

直接引用をするときには、カギ括弧「」を使います。引用をしたあとには、それがどこに書かれてあったのか、**出典**を示す必要があります。

!!! example "直接引用の例"
    Chomsky（1965: 23）は「人間が持つ言語能力は生まれつきの能力である」と主張している。

直接引用をするときには、原文に誤字脱字やタイポなどがあっても、そのまま引用します。たとえば、原文が以下のように「は」が「ば」となっていても、そのまま引用します。

!!! example "直接引用はそのママ"
    Chomsky（1965: 23）は「人間が持つ言語能力ば生まれつきの能力である」と主張している。

その際、自分が直接引用をするときに間違えて入力したものではないことを示すために、誤字脱字やタイポだと考えられるところに**ママ**と記入する場合があります（ルビを振ることも）。

なお、直接引用をする文章が長い場合には、地の文に埋め込むのではなく、段落を変えて示します（block quotation）。

### 間接引用（paraphrasing）
**間接引用**をするときには、直接引用のようにカギ括弧を使う必要はありません。もちろん、出典は示す必要があります。学部生のレポートや発表には、原文にある表現の一部だけを言い換える例がよくあります。

たとえば、以下の内容を、自分の卒論に間接引用で示したい場合、どうすればいいでしょうか。

!!! example "原文の例①"
    人間が持つ言語能力は生まれつきの能力である。その証拠は、人間のこころ、つまり、脳を…

以下のように、「持つ」の「持」をひらがなの「も」に、「は」を「が」に、「こころ」を「心」に、「つまり」を「すなわち」に入れ替えたものは、間接引用ではありません。「先行研究を自分のことばで言い換えなさい」と言われることがあると思いますが、以下のような例は「言い換え」とは言えない。

!!! warning "表現の一部だけを変えた間接引用の例"
    Chomsky（1965: 20）は、人間がもつ言語能力が生まれつきの能力だと主張している。その証拠は、人間の心、すなわち、脳を…

適切な間接引用の例を見てみましょう。今回は、以下の例を間接引用で示してみましょう。

!!! example "原文の例②"
    間接引用をするときには、引用符や段落の変更などは必要ない。しかし、間接引用が単語だけを置き換えて、原文と酷似していてはダメである。たとえば、次のような例は、この文章を間接引用のつもりで書いた剽窃である。

この内容を読んで、自分の卒論に間接引用で示すとしたら、たとえば、以下のような形になるでしょう。

!!! example "原文の例②を間接引用している例"
    ウィリアムス（2000: 150）によると、剽窃をしないためには、原文の意味をよく咀嚼し、自分の言葉で要約をして、原文と自分の文章において概念がどのように展開されているのか、読み比べる必要がある。

一方、以下の例は上の「原文の例②」とかなり違っているように見えます。しかし、説明のために用いられている概念・例などが、非常に似ていると言えます。このような場合、原文とは随分違っているように見えるけれども**剽窃**と見られる可能性があります。

!!! warning "間接引用のつもりで書いたけれども剽窃となりうる例"
    間接引用をする際には、本来の単語を他の単語で言い換えて、原文と似ているように見えてはいけないので、注意する必要がある。たとえば、この段落を間接引用した次の文章は剽窃である。

間接引用の他の例を見てみましょう。

!!! example "原文の例③"
    演劇は、文学の中で最も社会的な形態である。演者と観客との関係が現場において直接的に結ばれるからである。

これを間接引用で示すとしたら、たとえば、以下のようにすることができます。

!!! example "原文の例③を間接引用している例"
    レヴィン（2000: 150）の主張によると、「経験」という観点から考えた場合、演劇は文学の中で最も社会的な形態として捉えることができる。演劇は我々の目の前で広がるからである。

間接引用は「自分の言葉で」表現しなければなりません。ですから、原文を自分の言葉で言い換える練習を、繰り返して行う必要があります。直接引用とは違って、間接引用は自分の理解に基づいて書きますから、原文での主張を勘違いして理解し、それをそのまま間接引用として示す場合もあります。

なお、一般的に、引用する部分が重要だと考えられるときには、著者名を本文の中で直接言及する。（『[[알기 쉬운 학위논문 작성법]]』p.87参照）。

一般的に、引用する部分が重要だと考えられる場合には、著者名を本文の中で直接言及します（この方法の場合、焦点が自分自身ではなく、他の研究者に移ってしまう可能性があります）。そうでないと考えられる場合は、著者名を括弧の中に入れて示します。

!!! example "重要だと考えられる部分を間接引用する"
    Chomsky（1965）は、人間が持つ言語能力は生まれつきの能力であると主張し、その証拠として、人間の脳と…

以下のように著者名を括弧の中に入れて書く方法は、焦点を自分に置いたまま、参考文献を自分の主張を裏付ける実証的な根拠として活用できます。

!!! example "そこまで重要ではないと考えられる部分を間接引用する"
    生成文法では、普遍文法の存在が主張されている（Chomsky 1965）。そのため、生成文法の考え方は…

!!! example "他の間接引用の例"
    生成文法の研究に大きな影響を与えた研究者は、海の親であるチョムスキー自身以外にも、数多くいる（田中 1980; 鈴木 1990; 佐藤 2000; 堀川 2010; 田窪 2020など）。

### 要約（summarizing）
**要約**は、他の人が書いた文章を読み、中核となる部分を見つけてまとめる作業です。要約をするときには、原文の元の長さよりも短くして言い換える必要があります。上で話した間接引用をするときにも、要約が必要です。

以下に当てはまる場合は、直接引用よりは、間接引用や要約で示した方がいいでしょう。

- 以前の研究を評価するため
- 他の人の主張（反論）に言及するため
- 他の人の主張やデータを持ってきて、自分の主張や理由を裏付けるため

## 改行と空行
両者は区別して使いましょう。

- 改行：話の流れが変わってくるとき
- 空行：図表の前後（上下）や、節の区切りを表すために入れる。

論文はブログ記事や小説ではないので、そんなひんぱんに改行を入れることはありません。

## 参考文献の示し方
研究コミュニティによって、参考文献の示し方（要旨の書き方や脚注の示し方なども）は異なります。ということは、言語学を専門としている研究者の間で好まれる方法がある、ということです。

ここは積極的に、AIの力を借りて、参考文献の示し方を、言語学の分野で好まれる示し方で統一してみましょう。

### 書き方の癖
文章の執筆にAIを使うとしても、書いた人の癖が感じられる場合があります。ゼミ生が書いた文章を読んでいると、ただ文章を読んでいるだけなのに、その学生のことが頭の中に浮かぶことがあります。「いかにも彼（女）らしい文章だね」と、すぐわかるような場合が、結構あります。特に4回生くらいになると、それなりの付き合いもありますから、その人の書き方の特徴・癖などがなんとなく伝わります。

一方で、それがよくわからない、伝わらない学生の文章もあるわけです。かなり多くの時間をAIと過ごし、AIの文体的な特徴について考えてみたりしているうちに、AIの癖もなんとなく感じるようになっています。ときどき、学生が書いた文章からAIの匂いがする場合があります。その学生は、私が普段AIとどのような生活を送っているのか知っているのでしょうか。

## わけのわからない略語
- e.g.
	- ラテン語の「exempli gratia」の略。「for example」と読む。
- cf.
	- 「compare」の略。「比較せよ」という意味。
- ibid.
	- ラテン語「ibidem」から。「同書に」という意味。
- pとpp
	- 一つのページには「p」を、複数のページを示すときには「pp」を使う。
	- 「p.17」「pp.17-18」
- p.c.
	- 「**p**ersonal **c**ommunication」の略。日本語では「私信」。
		- Matthew Gordon (p.c.) tells us mp3 format could be problematic for some kinds of spectral analysis where precise frequency information is crucial (e.g. fricative spectra).（*Handbook of Descriptive Linguistic Fieldwork*. p.202）
		- しかし、安藤節子（私信）によると、或る特殊な条件の下でだけ使うのではあるが、前置詞が存在する。（『[世界の言語と日本語](https://opac1.lib.ehime-u.ac.jp/webopac/BB00406353)』（改訂版）p.6）
