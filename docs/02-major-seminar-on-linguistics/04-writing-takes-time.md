# 文章は「時間」が書く
あなたが天才でもない限り、数日で長文、かつ、論理的な構造の文章を書き上げることはできません。

卒業論文は、時間管理をすれば、誰でも書けます。「言わなくても知ってるよ！」と思うでしょ？でもやらない人がいるんですよ。

「バランスの取れた食事をしましょう」「定期的に運動をしましょう」「脂っこい食べ物や塩分は控えましょう」「アルコールは適量を守って飲みましょう」「タバコはやめましょう」と、いくら言っても聞く耳を持たない。道理で儲かる医者がいるわけだ。

「ショート動画は中毒になりますから本を読みましょう」「自分と他人を比べることでうつ病になる可能性がありますから、SNS中毒にならないようにしましょう」といくら言っても、聞かない人がいる。

「時間管理をちゃんとすれば、普通の卒論はみんな間違いなく書けるから」と、いくら言っても聞いてくれない学生がいるので、なぜそれが必要なのか、ここで触れておきたいと思います。

時間の管理こそが、卒業論文の質に影響を与えます。

## 一気書きしない
卒業論文は、長い時間（普通は数か月）をかけて、少しずつ積み上げていくものです。なぜかというと、文章というのは「書く → 読み返す → 直す → また読み返す → また直す」のサイクルを何度も回して、ようやくまともなものになるからです。

そして、このサイクルには時間が必要です。書いた直後に読み返しても、誤字脱字や論理的ではない部分など、問題点に気づきにくい。一晩寝かせて、翌日読み返すと、「あれ、ここ何を言いたかったんだっけ」と気づくようになります。一週間後に読み返すと、「ここの構成、根本的にまずいな」と気づくかもしれません。文章を書いた直後に、それを客観的に読むことは、なかなか難しい作業です。だから、文章は「時間」が書く、ということです。

## 逆算
たとえば、卒論の提出締め切りが、1月25日だとします。逆算してみましょう。

- 1月25日：最終提出
- 12月：全体の最終修正、体裁の調整
- 11月：考察の執筆、全体の通読と修正
- 10月：結果の執筆、データの最終分析
- 9月：データ収集の完了、分析の開始
- 8月：データ収集
- 7月：研究方法の確定、先行研究の整理
- 6月：テーマの確定、先行研究の読み込み開始

こうして見ると、6月にはもう動き始めないと間に合わないかもしれません。「まだ半年以上あるから大丈夫」と思っている人。卒論は、半年以上かかるからこそ、今始めるのです。

## 考えずに動く
「卒論が書けない」という相談を受けることがあります。話を聞いてみると、多くの場合、「書けない」のではなく「まだ始めていない」の方です。始めてさえいれば、どんなにひどい文章、いや、メモ書き程度だとしても、直すことはできます。しかし、白紙は直せません。

まず、研究テーマに関することを何でもいいから書いてみてください。メモでも箇条書きでもかまいません。それが卒論の最初の一歩です。

## 完璧な初稿を目指さない
「論文だから、草稿もちゃんとした文章で書かないと」と思っている人がいるかもしれません。しかし、最初に書く文章は、ひどくて当たり前です。

ひどい草稿でもいいので、早く書いて、それを直す時間を確保することの方が大事です。直す回数が多いほど、文章の質は上がります。そのためにはやはり、時間が必要です。

## ボーっとする時間
走り続けるのは無理です。卒論は長期戦なので、ところどころ、休む時間も必要になります。

[言語学ゼミのプレイリスト](https://www.youtube.com/watch?v=0iAF8TJAqp4&list=PLmprBniDXusp5HNjQHJqGfbcLYqF15KiT&pp=sAgC)（ゼミ生それぞれが好きなおすすめの1曲）でも聞きながら、脳と体を休ませる時間もちゃんと入れてください。

## 分散
人間がまともに集中できる時間の長さは、それほど長くないかもしれません。「就活も終わったし、集中して卒論を書く」と言っても、長続きしないかもしれません。そういうときには、卒論と、別の何かしらのプロジェクトを行き来しながら、並行的にやってみましょう。「逃げ口」というと、あまりいい響きではないかもしれませんが、必要なんです、そういうところが。

## 「時間」があるからこそできること
### 推敲
「論文を書くとき、一番やりたくない作業は何ですか？」と聞かれたら、私は「推敲」と答えます。もう、論文書き終わったから、そのまま出版してほしい。けど、論文の出版は、そう簡単ではありません。

待ちに待った自分の子どもが生まれたときの感情って、どのようなものでしょうか。体験したことがないのでわかりませんが、論文1本を仕上げたときの感情と、似ているところがあるんじゃないかな…と思います。子どもが生まれたときの感情は、きっと言葉では表せないほどだと思います。

一方、子育てはどうだろうか。しばらくは、細かいところまで面倒を見る必要がある。赤ちゃんが勝手に成長して、ちゃんとした大人になってくれると嬉しいけど、そうはならない。巣立つときまで（またはそれ以降も）面倒を見てあげないといけない。

それは論文も同じです。「論文を書き上げて終わり！」ではなく、出版されるまで面倒を見て、出版されてからも、その論文に対する責任を果たす必要があります。
